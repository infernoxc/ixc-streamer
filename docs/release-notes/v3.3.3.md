## ⬇ Install or update

1. Below, under **Assets**, click **`IXC-Setup-v3.3.3.exe`** and run it (or download `IXC-Suite-v3.3.3.zip`, extract it and double-click `Install.bat`).
   - **"Windows protected your PC"?** Click **More info**, then **Run anyway**. The checksums are in `SHA256SUMS.txt` below.

Your settings, accounts, rewards, sounds, queue and playlists stay (a backup is made first). **Going back:** install v3.3.2 the same way.

## What's new in 3.3.3

**IXC is now called IXC Streamer.** IXC Music and IXC ChatBox have been one program since IXC 3, and now the name says so.

- The dashboard, the installer and Windows "Installed apps" show **IXC Streamer**.
- The project lives at **[infernoxc/ixc-streamer](https://github.com/infernoxc/ixc-streamer)**. Old `ixc-chatbox` and `ixc-music` links still work, and update checks use the new address.
- Nothing else changes. The install folder, settings, OBS panels and OBS source names (`MUSIC — IXC Music Player`, `CHAT — IXC TTS`) stay the same, so nothing needs setting up again.

Everything from 3.3.2 is included: channel point rewards (Twitch and Kick), 20 sound effects, and alerts read aloud.
